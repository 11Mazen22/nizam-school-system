        11 Â· Photo / logo storageProceeding â€” hardened by audit Â§O-18
        RecommendLocal disk under /storage/uploads/&lt;type&gt;/, strict MIME + extension whitelist, images re-encoded on upload.
        ReasonOffline-only by nature, and re-encoding neutralizes disguised-executable upload attacks.

      Why student_enrollments exists
      The students table holds only biographical facts that don't change with the school year â€” name, date of birth, religion.       Index &amp; constraint strategy
      
        Every foreign key is indexed (MySQL does this automatically) plus explicit composite indexes on student_enrollments(academic_year_id, class_id) and teacher_assignments(academic_year_id, teacher_id) â€” the two hottest report queries.

        Reference tables (grades, subjects, classes, academic_years, teachers, students) use ON DELETE RESTRICT â€” nothing with active children can be hard-deleted; archive instead.
        Pure join tables (teacher_subjects, role_permissions) use ON DELETE CASCADE â€” the relationship, not the entity, disappears.
        Character set &amp; collation are explicit, not inherited. Added in Â§O-8: a default of plain utf8 or latin1 silently mis-stores or mis-sorts Arabic text, and the failure is invisible until someone notices garbled names months later.
        No hard-delete route exists in the UI for students, teachers, classes, subjects, grades, academic_years, or users â€” only archive/deactivate.       I.2 Â· Backup â€” corrected by audit Â§O-4

      I.3 Â· Restore â€” corrected by audit Â§O-5

  function setActive(id){

  }
  if('IntersectionObserver' in window){
    var io = new IntersectionObserver(function(entries){
      entries.forEach(function(entry){
        if(entry.isIntersecting){ setActive(entry.target.id); }
      });
    }, { rootMargin: '-15% 0px -70% 0px', threshold: 0 });
    sections.forEach(function(s){ if(s) io.observe(s); });
  }
  links.forEach(function(a){
    a.addEventListener('click', function(){ setActive(a.getAttribute('href').slice(1)); });
  });
