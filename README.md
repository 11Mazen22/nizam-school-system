# Nizam School System

**Version 1.0.0**

A comprehensive school management system designed for independent K-12 schools, packaged for simple, reliable deployment on self-hosted local networks.

## Architecture & Design
Nizam is a robust, monolithic PHP application built to run on XAMPP or similar standard web server environments. 
- **Backend**: Plain PHP 8.2+, following modern MVC patterns without a heavy framework dependency.
- **Database**: MariaDB / MySQL.
- **Frontend**: Bootstrap 5, jQuery, and Chart.js, fully bundled locally. No external CDNs are used to ensure the system is 100% functional offline (e.g., when the school's internet connection drops).
- **Localization**: Full English and Arabic (RTL) support built-in. Exports (PDF, Excel) natively handle RTL.

## Prerequisites
- **Web Server**: Apache (XAMPP recommended)
- **PHP**: 8.2 or higher
- **PHP Extensions**: `pdo_mysql`, `mbstring`, `gd`, `zip`, `intl`, `fileinfo`
- **Database**: MariaDB 10.4+ or MySQL 8.0+

## Local Installation / Setup
Nizam is designed for an "unzip and run" installation model, but requires pointing your web server's DocumentRoot correctly for the application router to function.
1. Download the Nizam `htdocs` release package.
2. Extract the folder into a location on your server (e.g., `C:\xampp\htdocs\nizam`).
3. **CRITICAL:** You must configure Apache so that the `public/` directory is the DocumentRoot. The application routes (like `/setup` and `/login`) require the application to run at the root of the domain/host.
   - *Option A (VirtualHost):* Create a VirtualHost (e.g., `nizam.local`) with `DocumentRoot "C:/xampp/htdocs/nizam/public"`.
   - *Option B (Change default):* Edit your `httpd.conf` and change `DocumentRoot` to `C:/xampp/htdocs/nizam/public`.
4. Create a blank database in MariaDB/MySQL (e.g., `nizam_prod`).
5. Navigate to your configured host in your web browser (e.g., `http://localhost/setup` or `http://nizam.local/setup`).
6. Follow the interactive Setup Wizard to:
   - Verify environment requirements.
   - Enter database credentials.
   - Initialize the database schema and default data.
   - Create the initial admin account.

## Configuration & Environment
All system configurations are managed via the `config/config.php` file, which is automatically generated by the Setup Wizard from `config.example.php`. 
- DO NOT manually edit `config.php` unless you are recovering from a server migration.
- DO NOT commit `config.php` to version control.

## Backup & Restore
Nizam includes a robust, pure-PHP backup and restore utility, removing the need for administrators to use `mysqldump` or phpMyAdmin.
- **Backup**: One-click process that generates a checksummed, dependency-ordered SQL dump including both schema and data.
- **Restore**: Guarded operation that validates file signatures, performs an emergency pre-restore backup, and carefully manages foreign key constraints.

## Security Considerations
- **Directory Protection**: A deny-all `.htaccess` file at the project root ensures that only the `public/` directory is accessible via URL.
- **Offline Reliability**: Zero external dependencies ensure the system cannot be compromised or broken by external network failures.
- **CSRF & Escaping**: All forms utilize CSRF tokens. All outputs are strictly escaped to prevent XSS.
- **Setup Lockout**: The Setup Wizard permanently locks itself upon completion to prevent malicious re-initialization.

## Troubleshooting
- **Missing Extensions**: The Setup Wizard will halt and list exact missing PHP extensions. Enable them in your `php.ini`.
- **Blank Pages**: Check the application log in `storage/logs/` or the Apache `error.log`.
- **RTL Issues in PDFs**: Ensure the bundled Arabic fonts (Amiri/Noto Naskh Arabic) in `vendor-assets/fonts/` are intact and readable by the web server.
